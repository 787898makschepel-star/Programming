# 🤖 Mwaves Shop Telegram Bot (Копия @mwavesrobot)

Полнофункциональный, модульный, высокопроизводительный Telegram-бот для автоматизированной продажи аккаунтов, подписок, цифровых лицензий и файлов на **Python 3.11+**, **aiogram 3.x** и **SQLAlchemy 2.0 (asyncio)**.

---

## 🚀 Основные возможности

### Клиентская часть (Client Side):
- 🛍 **Интерактивный каталог**: Древовидная навигация (Категории ➔ Подкатегории ➔ Товары) с отображением остатка в реальном времени.
- ⚡️ **Атомарная покупка**: Защита от race condition — при покупке аккаунта/ключа выдается уникальная не проданная строка из склада.
- 👤 **Личный кабинет**:
  - Баланс пользователя в рублях.
  - Пополнение баланса через **Telegram Stars (XTR)**, **CryptoBot** или банковскую карту.
  - История покупок с возможностью в любой момент повторно скопировать купленные ключи/аккаунты или скачать файлы.
- 📖 **FAQ, Отзывы и Поддержка**: Информационные разделы с прямыми ссылками на оператора.

### Панель администратора (Admin Side):
Вход по командам `/admin` или `/panel` (доступ только для ID из `ADMIN_IDS` в `.env`).

- 📦 **Управление товарами и категориями**:
  - Создание и удаление категорий в пару кликов.
  - Добавление товаров 3 типов:
    1. `Цифровой ключ / строка (аккаунты)` — штучный склад.
    2. `Файл` — неизменяемый файл (архивы, мануалы, софт).
    3. `Услуга / Ручная выдача` — с инструкцией для покупателя.
  - **Массовая загрузка склада**: загрузка `.txt` файла или текста в чат — бот автоматически разбивает файл построчно, добавляет в склад и показывает количество.
  - Изменение цен и удаление товаров.
- 👥 **Управление пользователями**:
  - Поиск по `Telegram ID` или `@username`.
  - Просмотр карточки: баланс, потрачено, количество заказов, дата регистрации.
  - Начисление и списание средств вручную.
  - Блокировка (бан) и разблокировка пользователя.
- 📢 **Умная рассылка (Broadcast)**:
  - Отправка текста или фото с форматированием всем пользователям.
  - Предпросмотр перед отправкой.
  - Устойчивость к флуд-лимитам Telegram (`TelegramRetryAfter`) и автоматический сбор статистики (доставлено, заблокировали, ошибки).
- 📊 **Статистика и аналитика**:
  - За сегодня / за 7 дней / за все время:
    - Новые пользователи.
    - Количество успешных заказов.
    - Общая выручка.
    - Топ-5 продаваемых товаров.

## ⚙️ Быстрый старт и установка

### Способ 1: Локальный запуск (Python 3.11+)

1. **Клонируйте проект и перейдите в папку**:
   ```bash
   cd c:\Users\78789\Programming
   ```

2. **Создайте и активируйте виртуальное окружение**:
   - На Windows (PowerShell):
     ```powershell
     python -m venv venv
     .\venv\Scripts\Activate.ps1
     ```
   - На Linux/macOS:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте `.env`**:
   Откройте `.env` и вставьте ваш Telegram ID в переменную `ADMIN_IDS`:
   ```ini
   ADMIN_IDS=ВАШ_ТЕЛЕГРАМ_ID
   ```
   *(Узнать свой ID можно в боте `@userinfobot`)*

5. **Запустите бота**:
   ```bash
   python bot.py
   ```

---

### Способ 2: Запуск в Docker / Docker Compose

Самый простой способ для продакшена (сервер VPS/VDS):

1. Убедитесь, что установлены `docker` и `docker compose`.
2. Запустите контейнер в фоновом режиме:
   ```bash
   docker compose up -d --build
   ```
3. Просмотр логов:
   ```bash
   docker compose logs -f
   ```
4. Остановка бота:
   ```bash
   docker compose down
   ```

## 💳 Настройка способов оплаты

1. **Telegram Stars (XTR)**:
   - Работает «из коробки» без внешних токенов. Пользователи могут пополнять баланс звездами Telegram прямо со своего аккаунта.
2. **CryptoBot (@send)**:
   - Создайте приложение в [@CryptoBot](https://t.me/CryptoBot) (раздел *Crypto Pay* ➔ *Create App*).
   - Скопируйте API токен и вставьте в `.env`:
     ```ini
     CRYPTO_BOT_TOKEN=12345:AAbcd...
     ```
3. **Банковские карты / ЮKassa**:
   - Получите `provider_token` в [@BotFather](https://t.me/BotFather) через `/mybots` ➔ *Payments* ➔ *ЮKassa*.
   - Вставьте в `.env`:
     ```ini
     TELEGRAM_PAYMENT_PROVIDER_TOKEN=...
     ```
